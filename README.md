# Rudbekija – 3D Model and AR Educational Application

An educational project combining 3D modeling in Blender with an interactive Augmented Reality (AR) application developed in Unity.

The project focuses on the Rudbeckia flower and allows users to learn about the plant through interactive 3D content and a knowledge quiz.

## Project Overview

The project consists of two main parts:

- **3D Modeling:** The Rudbeckia flower was modeled and prepared in Blender.
- **AR Application:** The 3D model was integrated into a Unity application where users can interact with the flower through an AR camera.

## Features

### Main Menu
The application provides access to the main sections:

- AR Mode
- Quiz
- Instructions

### Augmented Reality Mode

Users can use the device camera to scan the Rudbeckia flower image and view the 3D model in an augmented reality environment.

The AR scene includes interactive objects related to the flower. By interacting with these objects, users can access additional educational content such as:

- Images
- Videos
- Audio
- Informational objects

The 3D flower model can also be viewed from different angles.

### Quiz

The application includes an interactive quiz for testing the knowledge gained while learning about the Rudbeckia flower.

Users answer multiple-choice questions and receive a score based on their answers.
